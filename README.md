# Portfólio — Gabriel Cattuzo

Portfólio pessoal de **Gabriel Cattuzo**, estudante de Engenharia de Computação na PUC-Campinas e desenvolvedor full-stack.

O site apresenta minha trajetória, principais competências, projetos selecionados e formas de contato em uma interface moderna, responsiva e inspirada no universo de engenharia e desenvolvimento de software.

## Executando localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) 22 ou mais recente
- npm

### Instalação

Clone o repositório e acesse sua pasta:

```bash
git clone https://github.com/gabrielcattuzo/portfolio.git
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, abra [http://localhost:3000](http://localhost:3000) no navegador.

## Build de produção

Para gerar a versão otimizada:

```bash
npm run build
```

Os arquivos finais serão criados em `dist/client`.

Para visualizar o build localmente:

```bash
npm run preview
```

## Publicação na Vercel

O repositório já inclui um arquivo `vercel.json` com as configurações necessárias.

1. Publique o projeto em um repositório no GitHub.
2. Acesse a [Vercel](https://vercel.com/) e selecione **Add New → Project**.
3. Importe o repositório.
4. Confirme as configurações detectadas automaticamente.
5. Selecione **Deploy**.

Não são necessárias variáveis de ambiente para executar o portfólio.
